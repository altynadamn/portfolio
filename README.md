# portfolio

Personal portfolio of Zhomart Begaly — software engineer (backend, systems, automation), Astana.

Next.js 16 · React 19 · TypeScript · CSS Modules · Canvas 2D.
The background is a live ASCII field that reads Dostoevsky's "The Grand Inquisitor";
the cursor resolves the noise into text.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Optional: `GITHUB_TOKEN` enables the GitHub GraphQL API for the activity calendar
(without it, the public contributions page is used).
